# Content and Copy Report — Acornd

## Voice and Tone
Quiet expert colleague. Short, plain, reversible. Say what happened + what to do next. No hype, no mascot, no AI filler ("delve", "seamless", "powerful").

## Messaging Principles
- One idea per line; action-led verbs (Send, Steer, Queue, Abort, Rename, Forget).
- Numbers with units (12.4k tokens · $0.03); ids mono (`#1276`).
- Destructive actions name the object + consequence ("Forget workspace? History stays on disk.").

## Page-level Copy

| Page/Area | Copy Goal | Example Copy |
|---|---|---|
| Empty transcript | Invite first send | "Start a conversation" / "Send a message, or type `/` for commands." |
| Running header | State + recency + cost | "Working · last active 12s ago · $0.04" |
| Queued steer | Visibility | "Queued — joins after this tool round" |
| Inspector | Frame audit | "What the model saw, what the harness is doing, and where the tools run." |
| Settings caption | Scope honesty | "Takes effect on the next run / sandbox." |
| Tool collapsed | Evidence preserved | "Show output (412 lines)" / "Show less" |

## CTA System

| CTA Type | Example | Usage |
|---|---|---|
| Primary | Send ↑ / Create | Single per surface |
| Confirm | Rename / Forget | Dialog, destructive styled |
| Secondary | Open / Show output | Row / card |
| Tertiary | Back to conversation | Ghost xs |
| Danger | Forget / Delete (tombstone) | Protected in `…`, restorable |

## Empty / Loading / Error Copy
- Empty: "No conversations yet. Start one below." / "No messages yet. Send a message, or `/` for commands."
- Loading: "Working…", "Queued — joins after this tool round".
- Error: "Not sent — [reason]. Your draft is kept above. [Retry]" / "Blocked by guard: [rule]."

## Onboarding / Help Copy
First-run transcript hint + slash kbd + abort/steer one-liner. No tour.

## Phrases to Avoid
"Seamless / powerful / delight /超"; color-only "red row"; "No messages yet." alone; unexplained silent restores.
